# Arquivos de importação — uso restrito

Esta pasta contém o arquivo preparado com as 59 escolas de Canindé:

```text
escolas_caninde_credenciais.csv
```

O arquivo possui **códigos e PINs temporários**. Ele serve somente para a primeira carga pelo menu:

```text
SME > Usuários > Importar escolas
```

Depois de confirmar que os 59 acessos foram processados:

1. guarde uma cópia em local administrativo protegido, se a SME precisar;
2. apague o arquivo do computador usado na importação;
3. não envie esse arquivo para GitHub, WhatsApp público ou e-mail coletivo;
4. não coloque o CSV dentro da pasta `public`.

O sistema obriga a escola a trocar o PIN de 6 dígitos por uma senha pessoal de pelo menos 8 caracteres no primeiro acesso.

O arquivo `modelo_importacao_escolas.csv` não contém credenciais reais e pode ser usado como modelo para cargas futuras.
