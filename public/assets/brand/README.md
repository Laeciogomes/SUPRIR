# Identidade visual

- `logo-secretaria-educacao-caninde.png`: marca principal definitiva da Secretaria Municipal de Educação, usada no login, menu e relatórios.
- `logo-secretaria-educacao-caninde.webp`: versão otimizada da mesma marca.
- `logo-caninde-educacao-horizontal.*` e `logo-caninde-planejamento-horizontal.*`: mantidos como compatibilidade com bancos antigos, mas também exibem a marca nova.
- `brasao-caninde.webp`: símbolo compacto usado no menu, carregamento, favicon e marca de apoio dos relatórios.
- `simbolo-planejamento-sme.*`: mantido apenas por compatibilidade; foi substituído pelo brasão para evitar exibição da marca antiga.
