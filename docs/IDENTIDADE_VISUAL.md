# Identidade visual do sistema

## Marcas

- Marca horizontal: `public/assets/brand/logo-secretaria-educacao-caninde.png`
- Brasão compacto: `public/assets/brand/brasao-caninde.webp`
- Brasão / marca de apoio: `public/assets/brand/brasao-caninde.webp`
- Arquivos PNG em alta resolução permanecem na mesma pasta para uso gráfico.

A marca horizontal possui texto escuro e deve ser aplicada sobre fundo claro, branco ou amarelo suave. No sistema, ela aparece dentro de cartões claros no login, no menu e nos relatórios.

## Paleta principal

| Uso | Cor | Hexadecimal |
|---|---|---|
| Amarelo principal | Dourado vivo | `#FFD000` |
| Amarelo de apoio | Dourado escuro | `#8A6500` |
| Vermelho de destaque | Vermelho alaranjado | `#F04423` |
| Fundo institucional | Grafite | `#171717` |
| Texto principal | Quase preto | `#191919` |
| Fundo claro | Marfim suave | `#F7F7F5` |

## Aplicação no sistema

- Amarelo: ações principais, item ativo do menu, linhas de destaque e títulos de relatório.
- Vermelho: detalhe de contraste, contadores e alertas institucionais.
- Grafite: fundo institucional do login e da barra lateral, sempre com a marca dentro de área clara.
- Branco e marfim: formulários, tabelas e áreas de leitura.

## Acessibilidade

Texto preto é usado sobre o amarelo vivo. O amarelo escuro é usado quando a cor funciona como texto sobre fundo claro. Estados de sucesso, erro e informação mantêm cores próprias para não depender somente da identidade partidária/institucional.
