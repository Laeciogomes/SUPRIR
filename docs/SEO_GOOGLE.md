# SEO e indexação no Google — SUPRIR Educação

A V5.1.5 inclui metadados de busca, canonical, Open Graph, Twitter Cards, dados estruturados Schema.org, `robots.txt` e `sitemap.xml`.

## Antes de publicar

O `sitemap.xml` e o campo `Sitemap` de `robots.txt` usam como endereço padrão:

`https://suprir-educacao-caninde.pages.dev/`

Se o sistema usar um domínio próprio, substitua esse endereço nos dois arquivos antes da publicação.

## Depois de publicar

1. Abra `https://SEU-DOMINIO/robots.txt` e confirme que o arquivo aparece.
2. Abra `https://SEU-DOMINIO/sitemap.xml` e confirme que o XML aparece.
3. Cadastre o domínio no Google Search Console.
4. Envie `/sitemap.xml` no Search Console.
5. Use a inspeção de URL para solicitar indexação da página inicial.

O sistema continua protegido por autenticação. Os mecanismos de pesquisa devem indexar somente a página pública de acesso; conteúdo autenticado não possui URLs públicas próprias.
